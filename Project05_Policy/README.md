# Project 5 — Policy, Compliance and Summary

## Overview
This project consolidates the AI identity security policy,
compliance mapping and capstone presentation for SecureNova.

## Deliverables

### 1. AI Identity Security Policy
Location: `01_Policy_Document/`

Covers:
- AI agent identity lifecycle and access reviews
- Credential governance and 90-day rotation policy
- Incident response playbooks for credential leakage,
  compromised agent identities and prompt injection

### 2. Compliance Mapping
Location: `02_Compliance_Mapping/`

Contains mappings to:
- NIST AI Risk Management Framework
- OWASP LLM Top 10

### 3. Final Presentation
Location: `03_Presentation/`

Capstone presentation and demonstration materials.

### 4. Evidence
Location: `04_Evidence/`

Supporting screenshots for policy and compliance deliverables.
